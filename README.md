# FinBank Portal

A modern, responsive online banking demo application built for portfolio showcases and QA automation practice.

## Features

- **Dashboard** — financial snapshot with account balances, quick actions, and recent transactions
- **Accounts** — checking, savings, and credit card overview with real-time balances
- **Transfer Funds** — move money between accounts with validation and confirmation
- **Bill Pay** — schedule payments to saved payees with confirmation numbers
- **Transactions** — searchable/filterable history with category tags
- **Statements** — monthly statement metadata and download links
- **Investments** — investment portfolio view
- **API Documentation** — live endpoint reference with request/response examples
- **QA Automation Lab** — catalog of stable locators, intentional challenges, and test scenarios

## Tech Stack

- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS, shadcn/ui
- **Backend:** Supabase Edge Functions (5 REST endpoints) + PostgreSQL
- **State & Data:** React Query, Zod validation
- **Testing-friendly:** Stable `data-testid` selectors + intentional locator challenges
